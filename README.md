 * Full-Stack Blog Platform *
  A responsive blog platform where users can register, log in, publish posts, and join discussions through comments. The backend uses Node.js and Express.js to provide a RESTful API, with MongoDB storing users, posts, and comments.

* Features
1. User authentication — Users can create an account and log in securely.
2. Blog management — Users can create, view, edit, and delete blog posts.
3. Comments — Readers can share feedback and discuss individual posts.
4. Responsive interface — The layout adapts to desktop and mobile screens.

* Tech Stack
Node.js - Runs the backend application
Express.js-Defines RESTful routes for authentication, posts, and comments
MongoDB-Stores user accounts, blog posts, and comments

Usage
1. Register for an account and log in.
2. Create a blog post, enter a title and content, and publish it.
3. Open a published post to read it or leave a comment.
4. Edit a post to update its content or delete it to remove it from the platform.
